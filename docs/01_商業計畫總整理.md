## 1. 核心商業模式定位

**「台灣人的 AI 閒置額度時間銀行：供給者一鍵連結用不完的 Pro 訂閱額度賺分潤；買家付 199 元月費，頂級模型不用等 5 小時、用多少付多少、比官方便宜。」**

### 雙層混合水庫架構（Hybrid Pool）

1. **第一順位（高毛利主力）：供給者 OAuth 月費訂閱水庫（做法 1）**
   - 收集一般用戶每月用不完的 **Google Gemini AI Pro / Ultra**、**OpenAI ChatGPT Plus / Pro** 等月費訂閱容量。
   - 採用 **官方 OAuth / 裝置驗證碼（Device Code）** 連結，手機 App 用戶與電腦用戶皆免安裝任何瀏覽器外掛，也不用交出帳號密碼。
   - 即時讀取供給者帳號的 **5 小時滑動視窗與 7 天週視窗剩餘 %**。
   - 供給者可自訂「願意釋出的最大比例」（例如釋出 80%、保留 20% 自用），達到上限自動切斷保護自用額度，無縫接力給池子裡下一個供給者帳號。
2. **第二順位（100% 不斷線保底）：平台直連大廠 API / OpenRouter**
   - 當尖峰時段所有供給者訂閱帳號都達到釋出上限或冷卻時，閘道自動無縫切換至平台自有的大廠 API Key，確保買家前端永遠 0 等待、不斷線。

## 2. 做法 1 技術實作細節（已寫入系統 v0.2）

| 訂閱平台 | 授權連結方式（支援手機與電腦） | 剩餘容量同步接口 | 頂級模型對話呼叫接口 |
|---|---|---|---|
| **Google Gemini AI Pro / Ultra** | Google OAuth 2.0 PKCE（本機自動回呼，手機可貼回呼網址或匯入 Token） | `POST /v1internal:retrieveUserQuotaSummary`（讀取 5h 與 Weekly `remainingFraction` 剩餘 % 與 `resetTime`） | `POST /v1internal:streamGenerateContent?alt=sse`（支援 `gemini-4-argon-high`、`gemini-3-pro-high`） |
| **OpenAI ChatGPT Plus / Pro** | **手機 / 網頁裝置碼（Device Code Flow）** 或本機瀏覽器 PKCE OAuth | `GET /backend-api/codex/usage` ＆ 回應標頭 `x-codex-primary-used-percent`（即時同步 5h 與 7d 已用 %） | `POST /backend-api/codex/responses`（強制 `store: false` 無痕，不寫入供給者網頁歷史紀錄） |
| **xAI Grok／SuperGrok** | **手機 / 網頁裝置碼（RFC 8628 Device Code）**；可匯入 `~/.grok/auth.json` | `GET cli-chat-proxy.grok.com/v1/billing?format=credits` ＆ `/user?include=subscription` | `POST cli-chat-proxy.grok.com/v1/responses`（訂閱額度，非 api.x.ai 按量計費） |

## 3. 定價與分潤結構

### 買家端方案

| 方案 | 月費 | 用量計費 | 核心賣點 |
|---|---|---|---|
| **隨用隨付** | NT$ 0 | 官方等值價 9 折 | 免綁卡試用、體驗「不用等 5 小時」 |
| **Pro 暢行會員** | **NT$ 199 / 月** | **官方等值價 7 折**（內含 50 點體驗金＋日常輕量模型合理吃到飽） | 主力獲利方案：解決 5 小時時間鎖 |
| **微型團隊共享** | **NT$ 149 / 人 / 月** | 官方等值價 7 折（全團隊共用額度池） | 開立台灣統編發票、老闆看成員用量報表 |

### 供給者端分潤（以官方等值 100 元額度被消耗為例）

- **買家支付**：70 元（享 7 折優惠）
- **供給者分潤（80%）**：實拿 **56 元現金**（或選擇兌換 **1.2 倍 = 67 點平台算力點數**）
- **平台抽成（20%）**：14 元（加上每位會員每月 199 元門票收入）

## 4. 階段推進路線

1. **階段一（目前原型）：OAuth 訂閱池 ＋ 供給者節點出口 ＋ API 保底**
   - Gemini／ChatGPT／Grok OAuth；節點領憑證後由供給者裝置發上游；官方 API／OpenRouter 第二順位。
   - `REQUIRE_SUPPLIER_NODE=1` 可禁止平台代發 OAuth。
2. **階段二：會員 ＋ 金流 ＋ 多供給者調度**
   - 買家登入、NT$199 方案、綠界／藍新／LINE Pay、分潤結算。
3. **階段三：規模化混合水庫**
   - 更多供給者、成本熔斷、Rate limit、管理後台。
   - 仍不做住宅 IP／指紋偽裝。
