# 第 0 階段執行清單

目標：在寫任何程式之前，用最低成本回答三個問題：
1. 買家真的會付錢嗎？願意付多少？
2. 法律和金流上有沒有卡關的地方？
3. 能不能和大廠建立正式合作？

---

## A. 條款查核（已完成 2026-11-04；後續方向已覆寫）

曾記錄：供應商條款對「個人訂閱額度轉售／代他人使用」有限制，文件一度寫成「改以平台自有官方 API 為合規主線」。

**現況覆寫（以產品與程式為準）：**

- **產品主線仍是做法 1：供給者 OAuth 訂閱水庫**（見 `01`；`lib/oauth.ts` 可串 Gemini／ChatGPT／Grok）。
- 官方 API／OpenRouter 是**保底通道**，不是用來取代 OAuth 主線。
- **供給者節點 MVP 已落地**（見 `03`）：Token 領到節點本機、平台只派工；出口 IP 可對照。不做住宅 IP／指紋偽裝。

## B. 買家問卷

發放管道：Threads、PTT（AI_Art、Soft_Job、Tech_Job 等）、臉書 AI 社團、Discord、身邊朋友。
目標：至少 200 份有效回覆。

### 問卷題目

1. 你目前有付費訂閱哪些 AI？（複選）
   - ChatGPT Plus / ChatGPT Pro / Claude Pro / Claude Max / Claude Ultra / Gemini 付費方案 / 沒有付費 / 其他
2. 你每個月花在 AI 訂閱的總金額大約是？
   - 0 / 1～700 元 / 701～3,500 元 / 3,501 元以上
3. 過去一個月，你被「用量已達上限，請稍後再試」卡住過幾次？
   - 從來沒有 / 1～2 次 / 3～10 次 / 超過 10 次
4. 被卡住時你通常怎麼做？
   - 等它重置 / 換另一個 AI / 升級方案 / 放棄 / 其他
5. 你覺得自己每月的訂閱額度大概用了多少？
   - 不到 30% / 30～70% / 70% 以上 / 經常不夠用
6. 如果有一個平台：不用等、多種頂級模型都能用、用多少付多少，且日常問題吃到飽，你願意每月付多少會員費？
   - 不願意 / 99 元 / 199 元 / 299 元 / 499 元以上
7. 除了會員費，你預估每月會額外花多少在頂級模型上？
   - 0 / 100 元以下 / 100～300 元 / 300～1,000 元 / 1,000 元以上
8. 哪些功能對你最重要？（最多選三項）
   - 不用等 / 價格便宜 / 多模型切換比較 / 跨模型記憶 / 台幣與 LINE Pay 付款 / 統編發票 / 團隊共用額度 / 繁中客服
9. 你主要用 AI 做什麼？（複選）
   - 寫程式 / 寫作與文案 / 研究與報告 / 翻譯 / 學習 / 工作文書 / 圖片生成 / 其他
10. 你是以個人還是公司名義付費？
    - 個人 / 公司報帳 / 都有
11. 如果你的公司或團隊可以共用一個額度池並開統編發票，你會推薦公司使用嗎？
    - 會 / 可能 / 不會 / 我就是決策者
12. 上線時願意收到搶先體驗邀請嗎？（留 Email，選填）

### 判斷標準

- 第 3 題選「3 次以上」的比例 > 30%：痛點成立。
- 第 6 題選 199 元以上的比例 > 15%：定價可行。
- 第 12 題留 Email 數 > 50：可以進入第 1 階段。

## C. 律師諮詢問題清單

1. 平台向官方購買 API、再以加價方式提供給用戶，條款與法規上是否有問題？
2. 用戶預先儲值的金額，是否涉及《電子支付機構管理條例》或其他儲值相關規定？需要信託或履約保證嗎？
3. 儲值金的退款規則怎麼訂才符合《消費者保護法》？
4. 團隊方案開立統編發票的流程，以及是否可以開立 B2B 合約。
5. 用戶對話內容的個資處理：保存期限、跨境傳輸（資料送到美國的模型供應商）、外洩時的通知義務。
6. 服務條款、隱私權政策、內容使用規範的草擬。
7. 用戶利用平台產生違法內容時，平台的責任範圍與免責條款。
8. 公司型態建議（有限公司或股份有限公司）與營業項目登記。

預算：一次性約 5～10 萬元。可以先找新創法律諮詢資源（例如各地創業育成中心的免費諮詢）。
