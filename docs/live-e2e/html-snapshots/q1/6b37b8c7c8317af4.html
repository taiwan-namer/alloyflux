隨着人工智能硬件拋售加劇，英偉達及其競爭對手股價大跌。人工智能概念股是否面臨風險？
Anthony Peden
參與了話題 · 11/12 19:35

📊 資本構成明細：2026年11月12日，星期四


交易員們，早上好！
星期三是逆襲之日，人人都愛聽精彩的逆襲故事。$CoreWeave (CRWV.US)$上漲了25%，芯片股大幅飆升，標普500指數收盤點位僅比歷史最高紀錄低2.6%。納斯達克100指數基金（QQQ）自上週暴跌以來首次收於200日均線上方。隨後的……$英偉達 (NVDA.US)$不過，收盤後事態進一步惡化。《紐約時報》報道稱，黃仁勳又有了第二段婚外情，對象是一名公司高管；英偉達董事會於週三晚間召開會議，商討是否解除黃仁勳的首席執行官職務。目前尚未公佈任何決定。盤前英偉達股價下跌近6%，期貨亦走低。8點30分將公佈上週首次申請失業救濟人數，今晚還將迎來思科和應用材料的業績發佈。

☕ 一句話速覽：市場動態：受英偉達董事會考慮罷免首席執行官影響，期貨走低。

📉 關鍵價位
$標普500指數ETF-SPDR (SPY.US)$759.81美元（盤前報757.23美元，跌幅0.34%）。收盤價較200日均線（731.31美元）高出3.9%。50日均線爲764.96美元，與當前股價的差距不足1%。
$納指100ETF-Invesco QQQ Trust (QQQ.US)$690.38美元（盤前報685.80美元，跌幅0.66%）。收盤價較200日均線（681.71美元）高出1.3%，且盤前仍維持在該均線上方。
薯片：$半導體指數ETF-VanEck (SMH.US)$506.96美元（週三上漲4.82%），盤前報497.90美元（下跌1.79%）。200日均線位於523.11美元。

#1 XLK：走勢疲軟。此次領漲股迎來實質性催化——CoreWeave的業績顯示人工智能需求仍在增長。但XLK中權重最大的個股目前陷入領導層危機，尚未確定繼任者，該指數盤前下跌1.1%。應用材料今晚的表現有望提振該板塊。眼下，醫療保健板塊（+0.83%）和金融板塊（+0.22%）領漲盤前市場。

🔥 發生了什麼
📌 週三：標普500指數上漲1.31%，收於7,619.38點；納斯達克綜合指數上漲1.6%，收於25,466.19點。道瓊斯工業平均指數上漲254.60點，漲幅0.49%，收於52,486.49點。美國債券市場因退伍軍人節休市。
📌 人工智能熱潮：$CoreWeave (CRWV.US)$ +24.71%, $美光科技 (MU.US)$+11.89% 和$閃迪 (SNDK.US)$+13.69%，存儲芯片廠商領漲芯片板塊。$美國超微公司 (AMD.US)$上漲7.32%，$博通 (AVGO.US)$3.99%，以及$英偉達 (NVDA.US)$下跌2.87%至173.73美元，這是該股在連續兩日大幅下挫後的首個上漲交易日。
📌 收盤後消息：《紐約時報》報道稱，黃仁勳還與英偉達醫療健康業務副總裁金伯利·鮑威爾有染，而鮑威爾正是向他彙報工作的下屬。董事會於週三晚間召開會議，商討黃仁勳作爲公司掌舵人的去留問題。彭博社報道稱，董事會已委託一家外部機構物色繼任人選，並正在考慮任命一位臨時首席執行官。黃仁勳本人並無明確的接班人，他曾表示自己並不認同所謂的繼任計劃。盤後交易中，該公司股價下跌逾8%。
📌 影響擴散：隨着領導層質疑波及更廣泛的科技行業，全球股市回落，阿里巴巴因市場擔憂其芯片獲取渠道而下跌約7%。亞洲股市全線收跌：日經指數跌0.7%，韓國綜合指數跌0.6%，恒生指數跌1.3%，上證綜指跌0.7%。
📌 受美元走強影響，金價跌破4000美元關口。

👀 關注中的股票
🔴 $英偉達 (NVDA.US)$盤前報163.63美元（跌5.8%），週三收盤價爲173.73美元。董事會的決議可能於今日隨時出爐，而業績將於週二發佈。短短五天內兩大不確定性令該股成爲市場焦點，而非單純的數據驅動型標的。

🟢 $美國超微公司 (AMD.US)$盤前報576.71美元（漲4.3%），週三收盤價552.90美元（漲7.3%）。高盛將其列爲首選標的，且該公司持有約25億美元的Anthropic股份，後者據悉IPO認購嚴重超額。若英偉達的領先地位存疑，AMD顯然是替代供應商。

🟢 $德照科技 (TTEK.US)$盤前股價40.97美元（漲8.9%），週三收盤價37.61美元（跌7.5%）。這家水與環境工程公司公佈了創紀錄的2026財年每股收益，訂單儲備增長13%，並上調了2027年的業績指引，同時回購了價值1億美元的股票。
​

🔍 隱藏的寶石
$Resideo Technologies (REZI.US)$，週三收盤價23.00美元（漲18.3%）。Resideo生產家用恒溫器、安防及空氣質量產品（旗下品牌爲Honeywell Home）。今年該公司表現被市場忽視：自8月分拆分銷業務並下調業績預期後，股價已下跌約37%。作爲獨立公司，其首個盈利季度超出市場預期。營收爲7.27億美元，高於預期的7.164億美元；調整後每股收益爲0.52美元，高於預期的0.43美元；毛利率提升至40.4%。此外，公司在分拆後償還了11億美元債務。公司預計2026年營收爲29.3億至29.5億美元，調整後每股收益爲1.92至1.98美元。受此消息提振，該股成交量激增至近5倍正常水平，股價升至三個月新高，並重新站上50日均線（18.48美元）和200日均線（22.50美元）。
⚠️ 風險提示：Resideo 過去一年內已有24次股價異動幅度超過5%。其營業利潤仍較去年同期下滑，且公司僅指引低至中個位數的增長。Oppenheimer 維持「跑贏大盤」評級，但將目標價從27美元下調至25美元。該公司業務與房地產市場高度相關，10年期國債收益率爲5%，目前股價僅略高於200日均線，此前曾出現單日大幅跳漲（RSI約74）。
​

⚡ 核心觀點
週三證明，只要業績亮眼，人工智能板塊依然不乏買家。今日則將考驗該板塊能否在這家全球最大的芯片公司釐清掌舵者之際保持堅挺。任何董事會公告都將牽動整個市場，而不僅僅是英偉達一家。關注納斯達克100指數基金的200日均線（681.71美元）：該股昨日重新站上這一均線，若能在英偉達突發利空下穩守此線，將充分彰顯市場的韌性。今晚，思科和應用材料公司將揭示除英偉達之外的人工智能相關支出狀況。
